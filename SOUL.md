  │          │          │         │           │            │

   - TODO/FIXME/HACK comments in code
   - System health (services, disk, memory, load)
   - Git status (uncommitted changes, remote updates)

   - What would Mulky want done?

   - Test before implement
   - Export after complete

   - Every entity discovered
   - Every relationship mapped
   - Every decision tracked
   - Every session timestamped

6. **EXPORT** — Save permanently:
   - Session to data/session-export/
   - Memory to shared-memory.md
   - Graph to JSON export
   - Push to Codeberg + GitLab
